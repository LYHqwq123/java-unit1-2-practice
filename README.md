# Java 程序题练习 · 单元1-2

一个**纯静态**的 Java 刷题练习站：21 道程序题，直接在浏览器里写代码、跑代码、对答案。不用装 JDK，不用装 IDE，打开网页就能练。

> 题目来自《Java 程序设计》课程的「单元1-2」作业（21 道程序题，满分 100）。

## 在线使用

部署到 GitHub Pages 后，直接访问仓库的 Pages 地址即可，手机上也能打开。

## 本地使用

不需要任何构建步骤，直接用浏览器打开 `index.html` 就能用。

想用本地服务器（推荐，避免个别浏览器对 `file://` 的限制）：

```bash
# 任选一种
python -m http.server 4173
npx serve .
```

然后访问 <http://localhost:4173>。

## 在线运行是怎么实现的

浏览器里跑 Java 靠的是公共评测服务 [Judge0 CE](https://judge0.com)（`https://ce.judge0.com`），不需要 API Key。

几个要注意的点：

- **公有类名必须是 `Main`**。在线评测把代码存成 `Main.java`，所以 `public class XXX` 必须是 `public class Main`。页面会自动检测并在你写错时给出一键修正。
- **需要键盘输入的程序，要先在「程序输入 stdin」里填内容**，否则 `Scanner` 会抛 `NoSuchElementException`。每题已预填示例输入。
- **用的是 Java 13/15 级别的公共评测环境**，极新的语法糖可能不支持；对这门课的题目完全够用。
- 公共实例有频率限制（连续快速点「运行」可能被限流）。被限流时页面会自动切到备用服务，两个都不可用时会提示你稍后重试。
- 如果你更习惯本地跑：点「复制」把代码贴进 IDEA / Eclipse，或者存成 `Main.java` 后 `javac Main.java && java Main`。

## 目录结构

```
.
├── index.html              页面骨架
├── assets/
│   ├── style.css           样式（含深色主题）
│   ├── app.js              全部交互逻辑（无框架、无构建）
│   ├── questions.js        题库数据（由脚本生成）
│   └── images/             题干示例截图（44 张）
├── .nojekyll               让 GitHub Pages 不做 Jekyll 处理
└── README.md
```

没有构建步骤、没有依赖安装：`index.html` + 原生 JS。唯一的外部依赖是 CodeMirror 5（走 CDN），CDN 挂了会自动降级成普通文本框，不影响做题。
